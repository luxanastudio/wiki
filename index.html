LuxChatColor

Next-generation chat colors, interactive item previews, and automated chat moderation.

Introduction

LuxChatColor is an all-in-one chat customization powerhouse for modern Minecraft Paper servers. It replaces 3 to 4 fragmented plugins with a single, high-performance, asynchronous engine supporting full RGB hex colors, multi-stop gradients, hoverable item tooltips, snapshot inventory links, and an automated rule-based chat filter.

Key Features

🎨 Custom Head GUI
Interactive 54-slot menu built with custom skull skins, lock/unlock indicators, permission hints, and player statistics card.
🌈 22+ Colors & Gradients
Pre-configured legacy codes, modern hex palettes, multi-stop gradients, rainbow text, and bold/italic styles.
🗡️ [item] Hover Previews
Shows localized item name in chat with native client hover tooltips including enchantments, lore, attributes, and custom model data.
🎒 [inv] Click Previews
Generates expiring, single-use clickable inventory snapshots in chat revealing inventory, armor, and offhand contents.
🛡️ Smart Chat Moderation
Regex & word blacklist with violation ladders: automatic chat warnings, temporary mutes, and kicks.
⚙️ In-Game Visual Editor
Run /lccadmin gui to visually create, edit, reorder colors, permissions, and icons on the fly.

Installation

  1. Download LuxChatColor-1.2.0.jar.
  2. Drop the file into your server's plugins/ folder.
  3. Start your server to generate the configuration folder.
  4. Grant permissions to your donor or player groups, customize config.yml, and enjoy!

Color Picker GUI

When players run /chatcolors, they are presented with a 54-slot menu populated by custom-textured player skulls:

  • Status Indicators: Unlocked colors display a green checkmark and preview of the player's name with that color. Locked colors show a red cross with the exact permission required.
  • Profile Head Card: Positioned in the bottom center slot, rendered with the player's real Minecraft skin. It displays total unlocked colors, active style, and quick stats.
  • Reset / Clear: Clicking your active color unselects it, restoring normal white chat. Players can also type /chatcolors none.

Item & Inventory Previews

LuxChatColor brings rich, client-native hover and click previews directly to your chat:

Item Tooltips ([item])

Typing [item] in any chat message replaces the tag with the localized name and stack size of the item in the sender's main hand. Hovering over the chat name displays the client's exact tooltip, including custom lore, enchantments, potion effects, damage values, and CustomModelData.

Inventory Snapshots ([inv])

Typing [inv] generates a clickable link in chat. Clicking opens a read-only GUI showing the sender's full inventory, equipped armor, and offhand item at the time of sending.

  • Single-use & Expiring: Snapshot links expire after a configurable timer (default: 60s) to prevent spam.
  • Tamper-Proof: The inventory is a cloned read-only snapshot—items cannot be removed or stolen.

Chat Filter & Ladder

Automate your chat moderation with regular expression and keyword filters located under plugins/LuxChatColor/filters/:

  • Actions: Matches can be masked with asterisks, blocked with a warning, or forwarded to online staff via private alerts.
  • Automated Escalation Ladder: Violations accumulate per player and trigger automated punishments:
    • 3 Violations: Formal chat warning sent to player.
    • 6 Violations: Automatic 15-minute mute applied across server.
    • 9 Violations: Automatic kick from server.
  • Staff members with luxchatcolor.filter.bypass are exempt from filtering.

In-Game Visual Editor

Administrators with luxchatcolor.admin can type /lccadmin gui to open the visual live editor:

  • Create new color entries directly in-game.
  • Tweak names, descriptions, head textures, and slots without touching YAML files.
  • Assign wrappers (Hex codes, MiniMessage gradients, or legacy codes) with instant live preview.
  • Save changes immediately with automatic hot-reload.

Configuration (config.yml)

previews:
  item:
    enabled: true
    token: "[item]"
    cooldown-seconds: 5
  inventory:
    enabled: true
    token: "[inv]"
    expiry-seconds: 60
    show-ender-chest: false

moderation:
  enabled: true
  escalation:
    warning-violations: 3
    mute-violations: 6
    mute-duration-minutes: 15
    kick-violations: 9

LuxCustomRank

Self-service rank colors, custom titles, and user meta prefixes for LuckPerms.

Introduction

LuxCustomRank is the ultimate LuckPerms companion. It gives your VIPs, Donators, and players full self-service power to change their rank prefix color via a sleek player-head GUI or type a custom rank title using /customrank—without changing the global server group!

How It Works (LuckPerms User Meta)

Pure User-Level Scoping: LuxCustomRank injects a LuckPerms PrefixNode on the individual User (at priority weight 100).

Because the node is saved to the player's personal meta, it overrides their inherited group rank (weight 10-50) cleanly. Other players with the same group rank are completely untouched. When /rankclear is executed, the user node is cleared and the player seamlessly returns to their normal rank.

Installation

  1. Make sure LuckPerms is installed and running on your server.
  2. Download LuxCustomRank-1.0.0.jar and place it into plugins/.
  3. Start your server to generate the configuration files.
  4. Grant permissions (e.g. luxcustomrank.color, luxcustomrank.prefix) to your donor ranks!

Commands List

/rankclear /resetrank, /resetprefix luxcustomrank.clear Clears custom prefix and restores group rank.
/luxcustomrankadmin reload /lcra reload luxcustomrank.admin Reloads configuration and colors from disk.

Rank Colour Head GUI

Running /rankcolor opens a 36-slot menu loaded with custom textured player skulls representing vibrant Minecraft colors:

  • Per-Color Permissions: Each head checks for luxcustomrank.color.<name> (or luxcustomrank.color.*).
  • Live Preview: Hovering over any color head shows how your name and rank will look in chat with that color applied.
  • One-Click Apply: Clicking any unlocked head updates your personal LuckPerms prefix color instantly without server restarts.
  • Reset Slot (Slot 31): A barrier icon allows players to wipe their custom color and restore their original rank prefix anytime.

Custom Prefix & Titles

Players with luxcustomrank.prefix can define their own title with /customrank <title>:

  • Supports color codes and custom titles (e.g. /customrank &b[WIZARD]).
  • Directly sets a personal LuckPerms PrefixNode at weight 100 on the player's UUID.
  • To reset back to the default server rank, players simply type /rankclear.

Anti-Abuse Word Filter

LuxCustomRank prevents players from exploiting custom prefixes or impersonating server leadership:

  • Length Constraints: Configurable min-length (default: 2) and max-length (default: 16) limits.
  • Blacklisted Words: Configurable banned-words list in config.yml (e.g. admin, owner, mod, staff, vulgar words) blocks unauthorized titles automatically.

Configuration (config.yml)

prefix:
  # Maximum and minimum characters
  min-length: 2
  max-length: 16
  # LuckPerms meta weight (overrides default groups)
  weight: 100
  # Blacklisted words
  banned-words:
    - "admin"
    - "owner"
    - "staff"
    - "mod"
