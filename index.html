>_ Commands

Command Aliases Permission Description
/chatcolors /color, /colors luxchatcolor.use Opens the color selection GUI.
/chatcolors <name> /color <name> luxchatcolor.color.<name> Equips a color directly via name tag.
[item] or [i] /item, /i luxchatcolor.preview.item Displays held item with native client tooltip.
[inv] /inv luxchatcolor.preview.inventory Shares a clickable read-only snapshot of inventory.
/lccadmin gui /luxchatcoloradmin gui luxchatcolor.admin Opens the in-game visual editor.
/lccadmin reload /luxchatcoloradmin reload luxchatcolor.admin Reloads configuration and filters.

⛔ Permissions

Permission Default Description
luxchatcolor.use Everyone (true) Permission to open the color selection GUI.
luxchatcolor.color.* OP Access to all colors and gradients.
luxchatcolor.color.<name> OP Access to a specific color (e.g. luxchatcolor.color.crimson).
luxchatcolor.preview.item Everyone (true) Permission to post [item] tags in chat.
luxchatcolor.preview.inventory Everyone (true) Permission to post [inv] links in chat.
luxchatcolor.filter.bypass OP Bypasses swearing and chat filter rules.
luxchatcolor.admin OP Access to admin commands and GUI editor.

🎨 Color Selection GUI

Players type /chatcolors (or /color) to open a 54-slot menu built with custom textured skull skins and color blocks:

  • Status Feedback: Unlocked colors show a green checkmark and active name preview. Locked colors show a red mark with the exact permission required.
  • Player Head Card (Slot 49): Displays your active chat color style and personal skin.
  • Reset Barrier (Slot 45): Clicking the red barrier unselects your active color, restoring default white chat.

🗡️ Previews ([item], [i] & [inv])

Item Tooltip Hover Previews ([item] or [i])

Typing [item] or [i] in chat replaces the tag with the held item's localized name. Hovering over it in chat renders the client's native tooltip, displaying custom names, enchantments, lore lines, attributes, and attack speed:

Inventory Snapshot Previews ([inv])

Typing [inv] shares a clickable link in chat. Clicking opens a read-only snapshot GUI revealing the sender's main inventory, equipped armor, and offhand slots:

🛡️ Chat Filter

Rule files in plugins/LuxChatColor/filters/ match prohibited words and regex patterns with automated escalation ladders (Warning at 3, Mute at 6, Kick at 9).

The following versions and platforms are supported:

1.21.x ✓ ✓ ✓ 21

Required Plugin:

  • LuckPerms ↗ (Required) - LuxCustomRank sets user meta PrefixNodes directly in LuckPerms.

📥 Installation

Put LuxCustomRank-1.0.0.jar into your server's /plugins/ folder and restart it. Configure your permissions and you are set!

>_ Commands

Command Aliases Permission Description
/rankcolor /rc, /rankcolors luxcustomrank.color Opens the visual rank color picker GUI.
/customrank <title> /customprefix, /setrank luxcustomrank.prefix Sets your personal custom prefix or rank title.
/rankclear /resetrank, /resetprefix luxcustomrank.clear Clears custom prefix and restores group rank.
/luxcustomrankadmin reload /lcra reload luxcustomrank.admin Reloads configuration and color heads.

⛔ Permissions

Permission Default Description
luxcustomrank.use Everyone (true) Base permission for plugin usage.
luxcustomrank.color OP Allows opening /rankcolor.
luxcustomrank.prefix OP Allows setting custom titles with /customrank.
luxcustomrank.clear Everyone (true) Allows resetting rank back to default.
luxcustomrank.color.* OP Access to all rank colors.
luxcustomrank.color.<name> OP Access to specific color (e.g. luxcustomrank.color.gold).
luxcustomrank.admin OP Access to admin reload command.

⚙️ Configuration

File path: plugins/LuxCustomRank/config.yml

config.yml 
prefix:
  # Character limits
  min-length: 2
  max-length: 16
  # LuckPerms meta weight
  weight: 100
  # Prohibited words
  banned-words:
    - "admin"
    - "owner"
    - "staff"
    - "mod"

gui:
  title: "<dark_gray>Pick your Rank Colour"
  size: 36
  filler: "GRAY_STAINED_GLASS_PANE"
  reset-slot: 31

👑 Rank Colour GUI

Running /rankcolor opens a 36-slot GUI featuring custom-skinned player heads. Clicking any unlocked head updates the player's personal prefix color in LuckPerms without server restarts.

✏️ Custom Titles

Players with luxcustomrank.prefix can type /customrank &b[VIP] or /customrank &6[KNIGHT] to assign their own personal prefix.

🚫 Anti-Abuse Filter

Custom prefixes are strictly validated against character length limits and the banned-words list to prevent staff impersonation.
